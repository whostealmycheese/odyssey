## 🛠️ 개발 워크스테이션 환경 요약
- **Host OS:** Windows 11 Pro (WSL 2)
- **Guest OS / Shell:** Ubuntu 22.04 LTS (`bash`)
- **Container Engine:** Docker Engine 26.1.1
- **VCS / IDE:** Git 2.34.1 / Visual Studio Code (WSL Remote)

자세한 수행 로그, 스크린샷 검증 증거, 트러블슈팅 2건 및 핵심 개념 정리는 **[`01-dev-workstation/README.md`](./01-dev-workstation/README.md)**에서 확인하실 수 있습니다.
