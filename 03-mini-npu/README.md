# 🧠 Mini NPU Simulator: AI 가속기 MAC 연산 시뮬레이터

AI 딥러닝 칩(NPU)의 핵심 연산 단위인 **MAC(Multiply-Accumulate) 연산**을 Python 순수 문법으로 직접 구현하고, 크기별 패턴 인식 및 성능 분석을 수행하는 시뮬레이터 프로젝트입니다.

## 📌 프로젝트 개요
- **개발 환경:** Python 3.10+ (외부 라이브러리 없이 표준 라이브러리만 사용)
- **핵심 목표:**
  - 2차원 패턴 및 필터 간의 MAC 점수 계산 (반복문 직접 구현)
  - 라벨 정규화 (`Cross`, `X`) 및 부동소수점 오차(Epsilon = `1e-9`) 기반 비교 정책
  - `data.json` 데이터셋 일괄 판정 및 실패 케이스 원인 분석
  - $3 \times 3$부터 $25 \times 25$까지 크기 증가에 따른 $O(N^2)$ 시간 복잡도 실측 리포트
